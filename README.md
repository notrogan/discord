# UnDiscord

A theme based on [OldCord](https://github.com/milbits/oldcord) that contains some more UI reverts, as well as some changes to things I don't like

# Installation

## Vencord

**Online method**

Paste the following into `Settings > Themes`:

* `https://media.notrogan.com/discord/main.css`

## Other

Paste the following in the CSS file/window:

```css
@import url("https://media.notrogan.com/discord/main.css")
```
